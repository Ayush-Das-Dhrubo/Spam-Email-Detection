Spam Email Detection — Quick Setup
1.	Unzip the project folder anywhere on your computer.
2.	Open the folder in VS Code.
3.	Activate the existing virtual environment:
venv\Scripts\activate.bat
4. Run command (pip install flask scikit-learn pandas reportlab)
5. Run the Flask app:
python app.py

5.	Open a browser and go to:
http://127.0.0.1:5000/

6.	Test the app by typing or uploading emails.
7. Extra functionality: a PDF report download feature is also included.
